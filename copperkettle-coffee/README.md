# Copper Kettle Coffee House — Website Project

## Project Overview
A five-page website built for Copper Kettle Coffee House, a fictional
independent coffee shop, as the target organisation for this Portfolio of
Evidence. The site showcases the shop's story, full menu, payment
options, and allows visitors to enquire about catering and group bookings.

## Website Goals and Objectives
- Give customers an easy way to browse the menu before visiting.
- Make payment options clear up front — including that cash is accepted
  at every location — to reduce friction for walk-in customers.
- Generate catering and group booking enquiries through a dedicated form.
- KPIs: menu page views, catering enquiry submissions, growth in unique
  visitors month-on-month.

## Key Features and Functionality
- Homepage with hero section, today's specials, and a payment methods callout.
- About Us page with the shop's history, mission/vision, and a team roster table.
- Menu page organised by category (Coffee & Espresso, Tea, Pastries & Food)
  using definition lists, plus a repeated payment methods note.
- Bookings & Catering page with an enquiry form, including a payment
  preference field.
- Contact page with two locations, opening hours, embedded maps, a
  contact form, and a photo gallery — payment methods (cash, card,
  SnapScan) listed per location.

## Timeline and Milestones
- Weeks 1–4: Planning, research, and HTML structure (Part 1) ✅
- Weeks 5–8: CSS styling and responsive design (Part 2)
- Weeks 9–12: JavaScript functionality, SEO, and final testing (Part 3)

## Part 1 Details
Part 1 delivers the HTML structure and basic content only, as required:
- Five HTML pages (`index.html`, `about.html`, `menu.html`,
  `enquiry.html`, `contact.html`), each using semantic tags
  (`header`, `nav`, `main`, `footer`, `section`).
- A consistent navigation menu linking all five pages.
- A team roster built as a `<table>`, menu items built as `<dl>` lists,
  and opening hours marked up with `<time>` elements.
- Placeholder images stored in `/images`, including a custom logo
  (full and icon versions).
- Empty `css/style.css` and `js/main.js` files reserved for Part 2 and
  Part 3 respectively.
